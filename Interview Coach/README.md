# Interview Coach

A lightweight interview preparation dashboard for Computer Science Engineering students. It organizes practice into four tracks: CS fundamentals, problem solving, practical exposure, and behavioral fit.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Included

- Browser-based demo sign-in using a name and email address
- Question practice with multiple-choice feedback and open-response prompts
- Progress by category, completion totals, and a practice streak
- Saved profile and progress in the browser's local storage
- Responsive layout for desktop and mobile

The sign-in is a local demo and does not verify identity or synchronize progress across devices. A production deployment would need an authentication service and a persistent database.

The question topics and practice structure are informed by these guides:

Questions are written as practice prompts and concise explanations, with reflective questions intended to be answered in the student's own words.
